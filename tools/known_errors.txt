# known_errors.txt — 測試判定時「已知可接受」的引擎紅字白名單。
#
# 背景（2026-08-02）：走查／壓測腳本原本只讀 stdout 的 `FAILS=` 行，完全不看
# stderr 的 `ERROR:`。結果 15 章共 90 次「UVs are required to generate tangents」
# 與「敵方載具一台都沒生成」的 push_error 全程與「30/30 章 0 FAIL」共存。
# 現在紅字一律計入 FAIL，只有列在本檔的例外才放行。
#
# 規則：
#   ・一行一個「固定字串」片段（grep -F 比對，不是正規表示式）
#   ・每一條都必須在上一行寫明**為什麼可以接受**，沒有理由的一律刪掉
#   ・白名單只該收「已確認無害且無法在遊戲內修掉」的引擎雜訊，
#     凡是「設定看起來有、玩起來沒有」那一類，一律修，不准進白名單
#
# 目前：空的。刻意留空——寧可先看見全部紅字，再逐條決定，
# 不要一開始就替自己開後門。
