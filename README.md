# 戰場 BATTLEFIELD

戰場女武神（Valkyria Chronicles）式的 2D 回合戰術遊戲，使用 **14 國真實軍備**（公開資訊）。
零依賴 HTML5 Canvas，**手機／電腦開瀏覽器即玩**。

## 線上遊玩
部署於 GitHub Pages：<https://lemon558212.github.io/battlefield/>

## 特色
- 14 國陸海空三軍建制、17 個兵種、真實制式武器型號
- BLiTZ 戰術：CP 指令池 + AP 即時走位 + 警戒射擊
- 三軍剋制：反艦飛彈剋大艦、防空／戰鬥機剋空軍、魚雷只打海
- 戰爭迷霧（敵人需偵察）、9 張陸／海／空地圖
- 手機觸控：點部隊下令、點地圖移動、點敵人開火

## 操作
1. 選國家與地圖 → 部署（點兵種再點地圖放置）→ 開始戰鬥
2. 點我方部隊下令 → 點空地移動、點敵人開火 → 結束回合
3. 佔領敵主堡或殲滅敵軍即勝

## 開發
純靜態，`js/` 為引擎與資料、`GDD/` 為設計規格、`research/` 為軍備查證來源。
本機預覽：`python -m http.server 8422` 後開 <http://localhost:8422>。
