## 執行方式

本專案**沒有獨立的物理測試場景**，回歸測試是內建在主場景的驗收台裡
（走真實的部署→下令→操控路徑，不是拉一個空場景擺方塊）。這比另建
`tests/physics/physics_regression_test.tscn` 更能反映實際問題——本專案歷史上多次
「驗收台過但遊戲裡錯」，原因就是測試環境跟真實場景不同。

```bash
GODOT="/c/Users/User/Desktop/Godot_v4.7.1-stable_win64.exe"
"$GODOT" --path godot/ -- selftest    # 約 10 分鐘，全部判定
"$GODOT" --path godot/ -- e2e         # 約 1 分鐘，端對端流程
```

**⚠ 必須開視窗跑。`--headless` 會假性 FAIL**（停在「無章節按鈕」）。
跑完結束時會 segfault，`DONE` 已印出就算跑完，是關閉時的已知問題。

## 人工驗證步驟（自動化涵蓋不到的部分）

1. 雙擊 `godot/啟動遊戲.bat` → 選第一章 → 部署 → 點自己人進第三人稱。
2. **沙包**：走到沙包工事旁邊繞一圈，看腿會不會插進散落的袋子（本次修正）。
3. **水**：走進海灘的淺水，應明顯變慢；按 `Z` 應該趴不下去。
4. **二樓**：進建築、走樓梯，人應該站在二樓地板上而不是陷在一樓。
5. **手臂**：邊跑邊用 `Q`／`E` 快速轉視角，手臂與槍不應消失。
6. **趴坡**：走到坡地按 `Z`，身體應該順著坡躺，不是水平浮著。
