# 核心戰棋規則設計部

## 職責（文件第四節）
- 設計玩家回合、敵方回合、增援與結算階段
- 制定指令點數（CP）、角色重複行動（AP 遞減）與指揮官加成
- 規範移動、攻擊、技能、蹲伏、撤退、救援、補給及占領
- 設計任務型態：殲滅、占領、防守、護送、撤離、突破、救援、限時
- 建立戰場評價（回合數/傷亡/達成度）、失敗處理與難度規則

## 主要產出
GDD/01 戰鬥系統（規格真相）、回合狀態機、勝敗條件表、評價公式。

## 本專案落地
- 規格權威：`GDD/01-戰鬥系統.md`；改規則先改 GDD 再改碼
- 實作對應：js/game.js（回合/CP/狀態機）、js/combat.js（命中/傷害/迎擊）
- 現況：CP/AP遞減、警戒射擊、佔領主堡、30回合防守 已有；
  **待做**：護送/撤離/救援/限時任務型態（劇情章節需要）、戰場評價（S~C 級）
- 任務型態新增 SOP：GDD/01 定義 → data-story 章節掛 objective → game.checkVictory 擴充

## 完成定義
規則在 GDD 有定義、有實測（實際打一場觸發該規則）、與 AI/連線模式不衝突。
