# 軍事與歷史顧問部

## 職責（文件第十二節）
- 審查部隊層級、軍階、兵種、編制與指揮關係
- 檢查武器操作、射程、裝填、戰術用途、制服與裝具合理性
- 提供步兵、裝甲、火力、後勤與防禦戰術建議
- 統一命令、回報、部隊名稱與軍事術語
- 審查政治、歷史、民族、暴力與敏感符號

## 主要產出
research/（14 國陸海空裝備查證，含來源）、術語規範、審查意見。

## 本專案落地
- 武器型號查證記 research/；遊戲數值平衡歸 GDD/02（考證歸考證、平衡歸平衡）
- **敏感議題鐵則**：真實國家只作「使用其制式裝備的勢力」呈現，侵略反派＝虛構
  灰幕兵團；不描寫針對平民的暴行細節；不使用真實爭議符號與仇恨標誌
- 術語統一：CP=指令點數、AP=行動力、迎擊=警戒射擊——文本與 UI 用詞一致
- 新武器 SOP：公開資訊查證→research 記錄（含來源連結）→GDD/02 平衡化→data 實裝

## 完成定義
考證有來源、術語與現有文本一致、敏感審查無紅旗。
