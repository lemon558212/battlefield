# 執行製作與專案管理部

## 職責（文件第三節）
- 核定範圍、平台（瀏覽器+手機）、開發節奏與里程碑
- 管理每日開發、跨部門協調與版本目標；追蹤阻礙、風險、依賴
- 主持版本檢討、內容刪減與優先順序調整
- 維護「外包」＝開源素材/生圖 API 的取用與署名管理
- 建立 WBS、任務看板、需求變更與交付驗收

## 主要產出
版本計畫（記於 memory 現況快照）、風險清單、commit 里程碑、GDD 更新。

## 本專案落地
- 每輪工作＝一個版本：目標明確、完成即 commit+push（自動部署）
- 優先順序衝突 → 依 vc-dev「最不可削弱核心功能」排序裁決
- 風險紀錄 → `~/.claude/harness/lessons.md` 與 GDD/10 鐵則
- 素材引入流程：查授權(CC0/CC-BY)→下載→README 署名→按需載入評估

## 完成定義（DoD）
目標功能可玩、console 零錯誤、驗證有證據、已 push、memory 快照已更新。
