# UI、UX 與戰場資訊視覺化部

## 職責（文件第九節：UI＋UX＋資訊視覺化 三合一）
- UI：主選單、戰術地圖、角色選擇、CP/AP 狀態、瞄準命中與傷害預測、
  據點/任務/評價/編成/圖鑑/存檔介面
- UX：簡化「戰術地圖→角色行動」的操作層級；教學、錯誤預防、無障礙；可用性測試
- 資訊視覺化：可移動範圍、迎擊區、有效射程、掩體方向、高低差、危險區、路徑消耗
  ——清晰但不過度遮擋 3D 戰場

## 主要產出
js/ui.js、css/style.css、HUD 疊層（Engine3D.overlay）。

## 本專案落地
- 已有：部署卡、瞄準面板（命中率/部位）、血條、角色卡（showCharCard）、
  劇情選單/簡報/對話、連線介面、手機橫置與虛擬搖桿
- **待做**：迎擊威脅區顯示（敵警戒扇形）、路徑 AP 預覽（拖曳時顯示剩餘）、
  傷害預測（開火前預估）、章節評價結算畫、編成/圖鑑介面
- 三秒可讀鐵則（dept-02 支柱 4）：新資訊元素上戰場前自問——
  第一次看的人 3 秒內懂嗎？擋住 3D 戰場了嗎？手機拇指按得到嗎？

## 完成定義
桌機+手機雙尺寸實測、不遮擋準心與選中單位、色弱可辨（紅綠之外有形狀差異）。
