# 戰鬥系統、角色控制與遊戲程式部

## 職責（文件第七節：戰鬥程式＋控制相機＋存檔 三合一）
- 回合管理、指令點數、傷害、護甲與狀態；迎擊、掩體、視線、射程與爆炸判定
- 據點、目標、回合數與勝敗條件追蹤；戰鬥事件記錄與除錯
- 第三人稱移動、碰撞、地形貼合；瞄準、輸入緩衝；鍵鼠/觸控/搖桿
- 存檔：章節、角色、資源、評價；版本升級與損毀備援

## 主要產出
js/game.js、js/combat.js、js/camera3d.js、js/units.js、（未來）js/save.js。

## 本專案落地
- 架構鐵則：規則層（combat/fog/ai/net）與渲染層（engine3d/render3d）嚴格分離；
  渲染改動不得碰規則、規則改動不得寫死國家數值
- 古典 script 架構：跨檔 bare 識別子非 window.X；index.html 載入順序有依賴
- 事件流：Combat.fire → ev[] → Game.pushFx（唯一音效/特效入口）
- **待做**：save.js（劇情進度已有 localStorage，需擴充至編成/評價/多周目）、
  戰鬥事件日誌（QA 用 replay）
- 驗證：改邏輯必實跑「選國→部署→移動→射擊→擊殺→勝利」一輪

## 完成定義
console 零錯誤、一輪流程實測過、連線模式（net.js 同步）不破壞。
