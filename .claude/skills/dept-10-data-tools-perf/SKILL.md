# 資料系統、開發工具與效能技術部

## 職責（文件第七節：資料數值＋工具編輯器＋效能平台 三合一）
- 資料驅動：角色、兵種、武器、敵人、地圖、任務與對話全在 data 層
- 格式驗證：未知鍵報錯（MOD_KEYS 檢查）、重複 ID、版本差異
- 效能：AI/尋路/角色更新/陰影/粒子/後製優化；記憶體與資源載入；LOD
- 平台：桌機+手機瀏覽器、觸控/滑鼠、解析度適配

## 主要產出
data-*.js 架構、效能預算表（下）、驗證邏輯、按需載入機制。

## 本專案效能預算（超標即退件）
| 項目 | 預算 |
|------|------|
| 首頁載入 | ≤ 8MB（歷史事故：曾 36.9MB） |
| 幀時（滿編戰鬥） | 桌機 ≤ 16ms、手機目標 ≤ 33ms |
| 單一模型 | ≤ 4MB，兵種模型一律 lazy 載入 |
| 場景物件 | InstancedMesh 優先；draw call 增幅需量測 |

## 本專案落地
- 按需載入：MODEL_ASSETS lazy:true → _ensureModel；同 URL 去重
- 驗證工具：makeUnit 的 MOD_KEYS 檢查；買素材前 `du -sh` 評估
- **待做**：資料字典自動生成、幀時迴歸測試腳本、紋理記憶體盤點
- 量測 SOP：改動前後各量 30 幀平均（暖機 8 幀後），寫進 commit message

## 完成定義
預算表全過、量測數字入 commit、無新增全域洩漏（場景重建物件數不增長）。
