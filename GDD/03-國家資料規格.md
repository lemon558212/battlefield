# 03. 國家資料規格（data schema）
<!-- v1.0 | 2026-07-07 | data/nations/*.js 與 js/data-nations.js 的唯一 schema 權威 -->

## 1. Schema（一國一物件）

```js
NATIONS["taiwan"] = {
  id: "taiwan",
  name: "台灣（中華民國）",
  flagColors: ["#000095", "#FE0000", "#FFFFFF"], // 旗幟三色，UI 與單位塗裝用
  uniformColor: "#3d4f3d",   // 單位主色（俯視小人身體色）
  trait: { id: "homeland_defense", desc: "防守方時主堡守軍受傷 -20%" }, // 全國特性，一國一個
  units: {                    // 9 個兵種 key 必須齊全（見 02 檔 §1）
    rifleman: {
      label: "步兵",          // 該國建制稱呼，可在地化（如俄國 "摩托化步兵"）
      weapon: "T91戰鬥步槍",  // 真實制式武器名（查證見 research/）
      // 數值覆蓋：只寫「與 02 檔基準不同」的欄位，其餘由引擎套基準
      mods: { atk: +2, range: -10 }
    },
    // ... assault, mg, mortar, sniper, at, engineer, specops, tank
    specops: { label: "涼山特勤隊", weapon: "XT112突擊步槍", mods: {} },
    tank:    { label: "裝甲兵", weapon: "M1A2T 艾布蘭", mods: { hp: +40, ap: -10 } }
  }
};
```

## 2. 鐵則

1. `mods` 只准出現 `atk / shots / range / acc / hp / ap / def / cost` 八鍵；引擎白名單檢查，未知鍵直接 console.error。
2. 微調幅度 ≤ 基準 ±15%（02 檔 §3），總戰力分 ±3% 內。
3. `weapon` 與 `label` 必須能在 `research/各國軍備研究.md` 找到對應列；找不到 = 先補研究檔再寫資料。
4. 因零依賴且用 `file://` 也要能玩：資料檔不用 ES module / fetch JSON，一律 `js/data-nations.js` 單檔集中，以 `<script>` 載入。`data/nations/` 目錄保留給未來拆分，v1 不使用。

## 3. 新增國家 SOP（給弱模型，照抄執行）

1. 派研究 subagent 查該國 8 欄位裝備 → 追加到 `research/各國軍備研究.md`。
2. 複製本檔 §1 模板填入 `js/data-nations.js`，9 兵種齊全。
3. 驗收：開遊戲 console 無紅字、國家選單出現該國、`Game.autoBattle(新國,"usa")` 勝率 35%~65%。
