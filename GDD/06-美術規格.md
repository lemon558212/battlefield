## 1. 雙軌制（User 指定「程式化＋圖片並行」的落地）

```
繪製單位時：
  若 assets/units/{nationId}_{cls}.png 已載入成功 → 畫該圖（尊重真實軍種美術）
  否則 → 呼叫程式化向量繪製函式 sprites.js drawX(cls)（零依賴 fallback）
```

- 引擎永遠具備向量 fallback：即使一張 png 都沒有，遊戲照樣好看、可玩。
- 圖片放置規則寫在 `assets/README.md`：檔名 `{nationId}_{cls}.png`（如 `usa_tank.png`），
  48×48 透明背景、俯視、頭朝右（引擎依 facing 旋轉）。User 可隨時放圖，無需改碼。
- **能力誠實**：本模型只交付「精緻程式化向量 + 圖片掛載機制 + 空 assets 目錄與說明」。
  真實軍種照片有版權、AI 生圖需外部工具，皆不由模型擅自產生塞入；由 User 決定是否放圖。

## 2. 程式化向量繪製規範（sprites.js）

每兵種一個 `draw{Cls}(ctx, u, colors)` 函式，colors = {uniform, accent, skin, metal}。共通要素：

- **陸兵（land 人形）**：橢圓身體（迷彩色）＋圓頭盔（深色）＋武器輪廓（沿 facing 方向的短線/多邊形）＋兵種識別色臂章點。各兵種差異：
  - rifleman 標準步槍剪影；mg 較粗槍管＋兩腳架三角；sniper 長槍管＋鏡面反光點；
  - mortar 背迫砲板；at 肩扛筒狀；engineer 背工具包（方塊）；specops 深色貼身＋消音器；sam 背飛彈發射箱。
- **坦克/裝甲**：車體矩形＋砲塔＋沿 facing 砲管；履帶紋（兩側短線）；散熱器黃點（弱點提示）。
- **艦艇（sea）**：拉長船體梭形（灰）＋艦橋方塊＋依 facing 的主砲/飛彈；destroyer 大、missileboat 小快、lst 寬扁艙門、submarine 低矮潛沒感（半透明水線）。
- **飛機（air）**：後掠翼三角剪影＋機身；fighter 尖細、attacker 粗壯掛彈、gunship 直升機（旋翼圓圈＋機身）；air 單位畫陰影投影於地面表示飛行高度。

## 3. 配色（各國 uniformColor 已在 data-nations.js）

- 陸兵用該國 uniformColor（迷彩主色），accent 取國旗第 2 色。
- 敵我識別：我方描藍邊 `#7db4ff`、敵方描紅邊 `#ff9d8a`（維持 v1）。
- 迷彩紋理：身體橢圓上疊 2-3 個較深色斑塊（程式隨機但以 unit.id 為種子固定），避免純色呆板。

## 4. 品質判準（弱模型驗收用；非品味類）

1. 站在一起的 9 個不同陸兵，肉眼可區分兵種（造型差異，不只顏色）。
2. 不同國家同兵種，迷彩主色明顯不同。
3. 艦艇明顯比人形大（destroyer ≥ 40px 長），飛機有地面投影。
4. 選中單位有高亮環、血條/AP 條不被 sprite 蓋住。

## 5. 品味類的熔斷（誠實條款）

「整體氛圍夠不夠帥、配色順不順眼」屬品味決策：弱模型做到 §4 的客觀判準即算達標；
若 User 用「太陽春／不夠帥」等口語回饋，走 harness/02 品味流程做 2-3 變體給 User 選，不自行反覆微調。
